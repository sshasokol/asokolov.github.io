# Alexandr Sokolov CV

Personal CV website for international Data / BI Analyst job search.

## Structure

- `index.html` - Russian version
- `en/index.html` - English version
- `index_en.html` - redirect to the English version
- `assets/css/style.css` - shared styles
- `assets/js/main.js` - theme switcher and scroll reveal
- `assets/pdf/` - downloadable PDF versions

## How to Open

Open `index.html` in a browser for the Russian version, or `en/index.html` for the English version.

## Notes

The current profile image file in `assets/images/` is empty, so the page uses an initials avatar fallback. When a real professional photo is ready, add it as an optimized image and replace the avatar block in both HTML files.
